1 e 2 - A engenharia de software envolve basicamente criar e manter um software ao longo do tempo, é tudo q precisa acontecer para que um sistema continue funcionando, evoluindo e sendo útil com o passar dos anos.

A diferença da engenharia de software pra programação é que a programação é só uma parte da engenharia de software, a engenharia de software vai pensar em como manter a programação de determinado código por exemplo, como equipes vão colaborar e como o sistema reage a mudanças.

Já a de software comparada a outras engenharias historicamente tolerava erros, era feito sem um rigor formal, mudava rapidamente e tinha pouca padronização, porém hoje isso está mudando pelo simples fato de a engenharia de software estar começando a controlar aviões, carros, hospitais e estruturas críticas, aproximando-a do rigor das engenharias mais tradicionais.

3 - Testabilidade significa projetar o sistema de forma que seja fácil escrever testes, resultados sejam previsíveis, dependências possam ser simuladas e garantir a qualidade do sistema.

Recuperabilidade é a capacidade do sistema de detectar falhas, apagar o fogo e voltar a um estado consistente, minimizar perda de dados e voltar com as operações de sistema rapidamente.

Modularidade é dividir o sistema em partes menores, organizadas e independentes de forma que permita um trabalho em equipe mais eficiente, uma evolução mais segura e um risco menor de quebrar o sistema inteiro.

Extensibilidade é o quão fácil é para os desenvolvedores estender seu sistema, sendo um exemplo disso mods no Minecraft onde o sistema foi feito para aceitar extensões sem alterar o núcleo do jogo.

Desacoplamento é a capacidade de um sistema independência entre módulos por exemplo, melhorando a manutenção e as escalabilidade.

1 - Um exemplo de trade-off comum em jogos é a qualidade gráfica vs o FPS, pois maior qualidade gráfica menor o desempenho, porém qualidade gráfica menor melhor o desempenho, sendo uma decisão comum os jogos oferecerem um modo desempenho com mais FPS e um modo qualidade com melhores gráficos.

2 - Anti-cheat vs a performance e privacidade
No valorant por exemplo se utiliza um anti-cheat avançado que roda no nível do kernel e monitora os processos do sistema, porém isso consome recursos, aumenta a complexidade técnica e gera preocupação com a privacidade do usuário pois quanto mais segurança há maior uso do sistema e quanto menos monitoramento mais hackers.

3 - Realismo vs Diversão
Um exemplo de realismo nos jogos é o flight simulator q busca um realismo extremo, já de diversão o GTA 5 equilibra o realismo com diversão, a questão é quanto mais realista, mais complexo é a física do jogo, penalidades são severas e controles são difíceis, e isso pode frustar jogadores casuais  e reduzir a acessibilidade, causando um conflito de mais realismo menos acessibilidade, menos realismo menos fidelidade a realidade.
